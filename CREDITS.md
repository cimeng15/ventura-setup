# Kredit & Lisensi

Repo ini **hanya mengemas** (bundle) karya pihak ketiga agar mudah dipasang
ulang. Semua hak cipta tetap milik pembuat aslinya.

| Komponen | Pembuat / Sumber |
|---|---|
| `Apple.Ventura.Dark.P6`, `AppleSplash`, `AppleDark-ALL`, `Plasma.AppBay`, `Plasma.Flex.Hub` | zayronxio — https://store.kde.org/p/1886187/ |
| `WhiteSur` (GTK theme, dekorasi, kursor) | vinceliuice — https://github.com/vinceliuice/WhiteSur-gtk-theme |
| `Mkos-Big-Sur` (ikon) | zayronxio (fork Mojave CT icons) |
| `Apple-cursors` | komunitas KDE Store |
| `kwin-effects-yet-another-magic-lamp` | koryboc / AUR |
| `Kpple Menu` | komunitas KDE Store |
| `Window Title Fork` | komunitas KDE Store |
| `Ventura` wallpaper | zayronxio (CC-BY-SA-4.0) |

Lisensi masing-masing komponen mengikuti lisensi aslinya (umumnya GPL/LGPL/
CC-BY-SA). Skrip installer (`install.sh`, `bin/*`, `lib/*`) bebas dipakai ulang.
